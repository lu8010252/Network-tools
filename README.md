# 网络工具箱 V1.0

一个 Windows 桌面小工具(C# / WinForms,单文件),把网络排障和系统维护里常用的操作集中到一个窗口里:
看网络状态、一键切换 IP、Ping / 端口扫描 / 路由追踪、DHCP 与环路检测、共享管理、系统清理等。

> 当前仓库只有 `Form1.cs` 一个源码文件(没有 `.csproj`),需要自己建一个 WinForms 项目把它放进去,见下面「编译」。

## 功能一览

左侧是分组导航,点分组标题可以折叠/展开,点具体项目切换到对应页面。

### 🌐 网络诊断

| 页面 | 能做什么 |
|---|---|
| 状态看板与快捷切换 | 显示当前网卡、IP、子网掩码、MAC、获取方式(DHCP/静态)、链路速率(标明有线/无线),无线网卡还会识别 2.4G / 5G 和 WiFi 代数;检测网关、DNS、互联网是否连通,并查公网 IP。可一键切换 IP:**常用 0 段 / 1 段 IP 地址**(家庭、办公两套预设)、**自动获取 DHCP**、**自定义手动输入**,切错了可点**恢复上一次配置**。另有**一键生成诊断报告**(导出 txt,含 `ipconfig /all`)和**一键网络深度重置** |
| 局域网主机发现 | 选好网段后点**开始 ARP 交叉精准扫描**,列出在线主机的 IP、MAC、厂商,结果可导出 CSV |
| 高级 Ping 测试 | 五个子页:**单个 Ping**、**持续 Ping**(长时间监测丢包/抖动)、**批量 Ping**(一次测多个地址)、**网段 Ping**、**TCP Ping**(测指定端口是否通) |
| 端口开放扫描 | 高并发 TCP 端口快速扫描:填目标地址(默认 127.0.0.1)、端口列表(逗号分隔,默认常见端口 21,22,23,25,80,135,139,443,445,1433,3306,3389,8080)、并发线程数(默认 100) |
| 路由追踪溯源 | 填目标地址(默认 www.baidu.com)、最大跳数(默认 30)、超时毫秒(默认 1200),逐跳显示经过的节点和耗时,定位断在哪一跳 |
| DHCP 服务器检测 | 探测网内有哪些 DHCP 服务器在响应(排查私接路由器、多个 DHCP 冲突) |
| 局域网回路测试 | 检测交换机物理环路(会引发广播风暴),发测试包看是否绕回本机 |
| IP 冲突检测 | 检查某个 IP 是否被别的设备占用 |
| 网络共享管理 | 查看 / 新建 / 删除共享,打开共享文件夹;**一键修复共享访问问题**(修复工作组环境访问管理员共享被拒绝等),**启用 SMB1(兼容老设备)** |
| 摄像头设备扫描 | 扫描局域网里的摄像头 / 监控设备 |

### 🛠️ 系统维护

| 页面 | 能做什么 |
|---|---|
| 系统高级工具 | 一键打开常用系统工具:CMD、PowerShell、管理员 CMD、设备管理器、任务管理器、注册表、事件查看器、磁盘管理、服务、资源监视器、计算机管理、控制面板、远程桌面、网络连接、防火墙;以及清空 DNS 缓存、清空 ARP 缓存、查看当前网络连接 |
| 软件卸载 | 列出已装软件,**卸载选中的软件**;卸载后可**仅扫描残留(不卸载)**,清理残留的缓存/配置目录 |
| C盘深度安全清理 | **扫描垃圾大小**,分项清理:临时文件、浏览器缓存、缩略图缓存、Prefetch、Windows 更新缓存、安装包缓存、回收站;**查找C盘大文件(>300MB)** |

## 使用方法

1. 打开程序,默认进入「状态看板与快捷切换」,几秒内自动检测当前网络状态;网络变了可点**手动刷新状态 / 检测延迟**。
2. 左侧点分组和页面切换功能。各页面的结果区域通常支持**导出结果**或**右键菜单**。
3. 需要**修改网卡 IP / DNS、共享、注册表、清理系统目录、DHCP 探测、环路测试**等操作时,请**右键 → 以管理员身份运行**程序,否则会因权限不足失败。
4. 右下角**安全退出工具箱**用来正常关闭程序。

### 切换 IP 的预设

「常用 0 段 / 1 段 IP 地址」使用 `Form1.cs` 顶部写死的两套参数:

| | IP | 掩码 | 网关 | DNS |
|---|---|---|---|---|
| 1 段(家庭) | 192.168.1.222 | 255.255.255.0 | 192.168.1.1 | 223.5.5.5 / 114.114.114.114 |
| 0 段(办公) | 192.168.0.222 | 255.255.255.0 | 192.168.0.1 | 223.5.5.5 / 114.114.114.114 |

要换成自己的网段,修改 `Form1.cs` 开头 `homeIp / homeGw / workIp / workGw` 等几个变量后重新编译即可。
操作的网卡由程序自动识别(会跳过虚拟网卡和回环,锁定真实的有线/无线物理网卡),不用手动指定;如果电脑上有多块物理网卡,请先确认当前看板里显示的「操作网卡」是不是你要改的那块。

## 编译

环境:Windows + Visual Studio 2022(或 `dotnet` SDK),目标为 Windows 窗体应用。

1. 新建「Windows 窗体应用」项目,命名空间用 `NeworkTool`(与文件里一致;或改文件里的命名空间)。
2. 用本仓库的 `Form1.cs` 替换项目里的 `Form1.cs`,删掉自动生成的 `Form1.Designer.cs`(界面是纯代码构建的,不需要设计器文件)。
3. 保证 `Program.cs` 里是标准入口:`Application.Run(new NeworkTool.Form1());`
4. 生成并运行。需要管理员权限的功能,可在项目里添加应用程序清单(`app.manifest`),把 `requestedExecutionLevel` 设为 `requireAdministrator`,这样双击就以管理员身份启动。

## 注意

- 清理、卸载、重置网络、改注册表等操作会真实修改系统,使用前请确认;「一键网络深度重置」后通常需要重启网络或电脑。
- 公网 IP 查询会访问 `api.ipify.org` 和 `members.3322.org`;不联网时该项显示失败,不影响其它功能。
- 扫描功能仅限在自己管理的网络中使用。
